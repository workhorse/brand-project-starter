# Changelog

## 0.2.0 (2026-10-19)

- `node scripts/check.mjs`: checks tokens, `tokens.css`, contrast pairs, the
  site's CSS and every rule's four parts. No dependencies.
- Rules split into exact rules (they point at a token) and judgment rules,
  with two worked examples from an invented brand.
- The direction template asks for the board it came from, the brief's words,
  what the room said, what the alternatives cost, and the first rules.
- `04-brand/tests/`: a home and a receipt template for testing the rules on
  an AI model.
- `write-rules` skill, and a Commands and Skills section in `AGENTS.md` so
  every tool finds them.
- `space.measure` token; the site no longer types a width by hand.
- Scripts are MIT licensed; everything else stays CC BY 4.0.

## 0.1.0 (2026-09-30)

- First public version: stage folders, `AGENTS.md`, four skills, DTCG
  tokens, a landing page shell, and `ABOUT-ME.md`.
