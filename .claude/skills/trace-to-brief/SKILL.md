# Trace to the brief

1. Read `BRIEF.md` and `01-brief/creative-brief.md`.
2. List the decisions in the work being reviewed.
3. For each one, name the brief section it answers and quote the words it
   answers. If none, say "answers nothing in the brief" and ask whether the
   brief is missing something or the decision should go.
4. List brief sections that nothing in the work answers yet.
5. Do not change the brief. If it looks wrong, say so and let the student
   revise it with a new date.
