# Write in the brand's voice

1. Read `04-brand/voice.json`. If `tone` and `rules` are empty, stop and tell
   the student the voice is not written yet; offer to help them draft it from
   `03-explorations/language.md`, but do not invent it.
2. Read the brief sections that matter for this copy, at least 4 Audience,
   7 Message and 10 Tone in `01-brief/creative-brief.md`.
3. Write the copy. Use `preferredTerms`, never `bannedTerms`.
4. Run the `check` skill on what you wrote and fix what it finds.
5. Show the student the copy and name the brief section each piece answers.
6. If the student corrects you the same way twice, propose a line in
   `04-brand/voice-queue.md`. Never edit `voice.json` yourself.
