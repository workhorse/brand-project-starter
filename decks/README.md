# decks

Every deck, board and brief you present or turn in, as a PDF, named with the date first so they sort:

    2026-09-21-pitch.pdf
    2026-09-30-creative-brief.pdf
    2026-10-14-explorations.pdf

Git cannot show what changed inside a picture, so the dated name and a line in `LOG.md` do that job. Recordings (MP4) are too big for the repo: upload them where the assignment says and put the link in `LOG.md`.
